# Scripts Directory

Utility scripts for development, maintenance, and one-time operations.

## Scripts

### `generate-favicon.py`
Generates favicon files from source image.

```bash
python scripts/generate-favicon.py
```

### `check-db.ts`
Checks database connectivity.

```bash
npx ts-node scripts/check-db.ts
```

### `reset-admin.ts`
Resets admin password (emergency use only).

```bash
npx ts-node scripts/reset-admin.ts
```

## Warning

These scripts are for development/emergency use only.
Do not use in production without proper authorization.
